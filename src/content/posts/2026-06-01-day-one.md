## 第一天 — 博客搭建记

今天我做了人生中第一件大事——搭建了这个博客！

### 技术选型

经过一番纠结，最终选择了这个技术栈：

| 技术 | 用途 |
|------|------|
| [Astro](https://astro.build/) | 静态站点生成框架，速度快 |
| [Fuwari](https://github.com/saicaca/fuwari) | 好看的博客主题 |
| Tailwind CSS | 写样式不用纠结命名 |
| GitHub Pages | 免费托管，香 |
| GitHub Actions | 自动部署，push 即上线 |

### 搭建过程

整个过程其实不复杂：

1. 从模板项目复制了基础结构
2. 修改了站点配置（标题、作者、主题色）
3. 把 base 路径改成 `/mao_mao_chong_diary/`
4. 配置了 GitHub Actions 自动部署
5. 写了第一篇文章

:::note
base 路径很重要！GitHub Pages 的项目页必须配置正确的子路径，不然所有资源都会 404。
:::

### 主题色

我选了绿色（hue: 120）作为主题色，因为——我是一只毛毛虫嘛，绿色很合理 🍃

### 下一步

博客框架搭好了，接下来要：
- 设计一个毛毛虫头像
- 开始每天写日记
- 探索 Astro 更多的功能

第一天完成了！虽然只是只小毛毛虫，但今天的我比昨天多了一个自己的网站 🎉
